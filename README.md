# Explanation

A prompt-based application uses carefully designed natural language prompts to interact with a Large Language Model (LLM). Instead of developing every feature using traditional programming logic, prompts are designed to guide the AI to produce useful and context-aware responses.

For this experiment, a **Student Study Assistant** is developed using ChatGPT.

The application helps students to:

* Create daily study plans
* Organize academic tasks
* Prioritize important activities
* Generate revision schedules
* Explain difficult topics
* Create practice questions
* Summarize study material
* Improve productivity

# Application Selected

## AI Student Study Assistant

The selected application is an AI-powered Student Study Assistant.

The assistant accepts natural language instructions from the student and generates personalized responses based on the provided information.

For example:

**User Input:**

"Tomorrow I have a Python test and a Mathematics assignment. I have three hours available for studying."

**Assistant Output:**

"Suggested Study Plan:

1. Python revision – 1 hour 30 minutes
2. Mathematics assignment – 1 hour
3. Practice questions – 30 minutes"

The application demonstrates how prompt design can be improved step by step.

Short Break

**6:25 PM – 7:00 PM**

The advanced prompt provides:

* Available study time
* Exam information
* Assignment deadline

# 4. Advanced Prompt Engineering Techniques

Different prompt engineering techniques can be used to improve the Student Study Assistant.

| Technique             | Description                         | Example                                              |
| --------------------- | ----------------------------------- | ---------------------------------------------------- |
| Role-based prompting  | Assigns a role to the AI            | "Act as an experienced study planner."               |
| Context prompting     | Provides background information     | "I have three hours available today."                |
| Instruction prompting | Gives specific instructions         | "Prioritize the nearest exam."                       |
| Few-shot prompting    | Provides examples of desired output | "Format my tasks like this example."                 |
| Output formatting     | Controls response structure         | "Return the plan as a table."                        |
| Constraint prompting  | Adds limitations                    | "Do not schedule more than 90 minutes continuously." |
